# GoNews — RSS-агрегатор (пет-проект)

GoNews — это пет-проект, созданный с целью отточить навыки backend-разработки на Go: работу с сетью, конкуренцией, парсингом данных, взаимодействие с базой данных, организацию архитектуры и создание полноценных REST API-сервисов.

Проект представляет собой RSS-агрегатор, который:

- собирает новости из нескольких RSS-источников,
- очищает и нормализует их содержимое,
- сохраняет в PostgreSQL,
- предоставляет REST API для доступа к данным.

Основной фокус — backend на Go, построенный с использованием реальных паттернов и практик продакшен-уровня: worker pool, context-based graceful shutdown, структурированный код, модульность и подготовка к масштабированию.

К проекту также подключён Frontend (Next.js) — он написан не мной, а адаптирован как дополнительная опция для визуализации результатов. Он не обязателен для работы сервиса, но помогает удобно просматривать данные.

## Цели проекта

Проект создан для изучения и закрепления:

- разработки сервисов на Go (API, HTTP-сервер, маршрутизация);
- работы с БД и ORM (GORM + PostgreSQL);
- конкурентности (goroutines, channels, worker pool);
- корректного завершения работы сервера (graceful shutdown);
- обработки данных (XML, sanitization, нормализация текста);
- проектирования и структуры сервисов;
- практики разработки пет-проекта "как для GitHub портфолио".

## Основные возможности

- Параллельная загрузка новостей через worker-pool
- Очистка HTML-контента из RSS с помощью bluemonday
- Хранение данных в PostgreSQL
- REST API для получения новостей
- Принудительное обновление RSS-ленты
- Health-check
- Полный graceful shutdown (SIGINT/SIGTERM, context, закрытие соединений)
- Возможность запуска дополнительного frontend-интерфейса

## Запуск backend-сервера

### 1. Установить зависимости

```bash
go mod download
```

### 2. Настроить базу данных (Docker)

```bash
docker-compose up -d
```

### 3. Переименовать config.json.example в config.json и указать пароль (если используете docker-compose, то пароль необходимо указать такой же как и в docker-compose.yml)

### 4. Запуск

```bash
go run main.go
```

## REST API

### Получить новости

```bash
GET /news?limit=5
```

### Принудительное обновление

```bash
GET /news/refresh
```

### Проверка состояния

```bash
GET /news/health
```

## Опциональный запуск Frontend

Фронтенд расположен в каталоге `frontend/`.

Он не обязателен для работы backend-а, но позволяет удобно просматривать собранные новости.

Запуск:

```bash
cd frontend
npm install
npm run dev
```

## Технологии

**Backend:**

- Go 1.25
- Gin
- GORM
- PostgreSQL
- XML + bluemonday
- Worker Pool
- Context + os/signal (graceful shutdown)

**Frontend (опционально):**

- Next.js
- React
- TypeScript
- Tailwind CSS
